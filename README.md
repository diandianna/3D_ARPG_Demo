# 3D ARPG Demo

一个基于 Unity 的 3D 动作 RPG 演示项目。包含完整的角色控制、战斗、成长系统，以及**自研 TCP 二进制协议 + C# 服务器**的多人联机。

> **仓库说明**：为控制体积，本项目**未包含大型贴图/UI 图片资源**（PNG/TGA 及 3ds Max 源文件，本地开发时完整保留）。仓库聚焦于**代码、场景、Prefab、动画控制器、模型（FBX）**等结构；画面效果请见下方演示视频（录制中）。

## 技术亮点

- **连招与伤害判定帧**：5 段连招由 Animator 状态机 + ComboStep 参数驱动，动画事件精确控制伤害判定帧，命中盒去重避免一次攻击重复判定
- **自研网络协议**：`[4字节总长][4字节类型][数据]` 二进制协议，处理粘包/分包 + 心跳保活；客户端权威位置同步 + 指数平滑插值
- **怪物 AI**：FSM 状态机（Idle/Chase/Attack/Hurt/Dead）+ NavMeshAgent 寻路，继承基类做差异化；Boss 多阶段（开发中）：阶段转场（回血 + Rage 变身 + 短暂无敌）、霸体/韧性防无限连
- **差异化玩法**：灵魂附身——子弹时间 → 灵体飞行选敌 → 附身操控怪物，实现『玩家-怪物』控制权切换与回归闭环，附带灵魂完整度 / 理智代价机制
- **AI 辅助开发**：使用 Claude 辅助方案设计与疑难 Bug 定位（联机同步、伤害链路排查），独立完成「客户端 + 自研服务端」

## 功能特性

- **账号系统**：注册 / 登录，服务器持久化玩家数据
- **角色控制**：相机相对移动、连招攻击、硬直、受击反馈
- **战斗系统**：攻击判定（AtkTrigger）、伤害飘字、怪物 AI（FSM + NavMeshAgent 寻路）
- **子弹时间**：BulletTimeMgr，慢动作击杀
- **附身系统**：附身怪物（灵魂完整度 / 理智值）
- **记录系统**：死亡日志、灵魂碎片
- **联机**：自研长度头 + 类型字节的二进制协议，黏包/分包处理，多人房间、位置同步

## 运行方式

### 客户端

1. 用 Unity Hub 打开本项目（Unity 2022.3.54f1c1）
2. 打开场景 `Assets/Scenes/BeginScene.unity`
3. 点击 Play

### 服务器

服务器是独立项目，不在本仓库内：

```
D:\develop\My_Course\C++&C\3DArpgServer
```

启动方式（监听 `127.0.0.1:8080`）：

```bash
cd 3DArpgServer
dotnet run
```

> 注意：服务器地址写死为 `127.0.0.1:8080`（本地测试）。需要跨机器联机时要改成局域网 IP。

## 目录结构

```
Assets/Scripts/
├── Base/        # 基础类（角色移动 BaseMove 等）
├── Data/        # 数据类
├── Mgr/         # 管理器（GameDataMgr、SocketMgr、SyncMgr 等）
├── Monsters/    # 怪物与 AI
├── Scene/       # 场景逻辑
├── TextScript/  # 文本相关
└── UI/          # UI 面板
```

## 联机协议简述

- 消息格式：`[4字节总长][4字节类型][数据...]`
- 消息类型：登录 / 注册 / 更新 / 攻击 / 移动同步 / 心跳 / 多人同步 / 多人联机
- 网络模型：**客户端权威（方案 A）**，服务器只转发；已理解服务器权威 + 预测回滚（方案 C）原理，留待升级
